# Blender Grease Pencil Experiment

## Goal
Test Blender as an independent 2D animation engine.

## Rules
- Do not modify Rewind.
- Do not modify CopyPaste.
- Do not modify VisualDeenTest.
- Do not change existing Remotion files.
- Keep this experiment isolated.

## Test Plan
1. Check Blender availability in GitHub Actions.
2. Create one simple 2D character.
3. Animate a few basic movements.
4. Render a short video.
5. Test importing the rendered output into Remotion.

## Current Status
Planning only. Blender has not been installed or integrated yet.
